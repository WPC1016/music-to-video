# 提示词库

六段提示词，对应制作流程的第 0.5–6 步。**每一段都是完整可粘贴的**，把 `{{...}}` 换成你的内容即可。

用法：按 00 → 01 → 02 → 05 → 03 → 04 的顺序走。前一段的输出是后一段的输入。

| 文件 | 几轮 | 什么时候用 | 输出放哪 |
|---|---|---|---|
| `00-素材盘点.md` | 1 | **建完目录、写方案之前** | 素材进 `songs/<歌>/assets/`，登记进 `asset-manifest.json` |
| `01-歌词解读.md` | 1 | 拿到 mp3+lrc 之后 | `songs/<歌>/concept/01-歌词解读.md` |
| `02-MV概念.md` | **2** | 解读完之后 | `songs/<歌>/concept/02-MV概念.md` |
| `05-风格定义.md` | **2** | 方向定了之后 | `songs/<歌>/concept/00-风格定义.md` |
| `03-分镜.md` | 1 | 概念和风格都定了 | `songs/<歌>/concept/03-分镜表.md` |
| `04-图像提示词.md` | 1 | 分镜定稿后 | `songs/<歌>/concept/prompts/NN-名称.md` |

> 顺序看起来怪（05 排在 03 前面），是因为**先定风格再切分镜**，否则分镜画出来的东西风格会散。文件名按流程编号，读的时候按上表顺序走。

## 00 别跳过

`00-素材盘点` 问的是「你手上有没有现成的东西」：人物设定、风格参考、实拍背景、视频片段。

有没有，决定后面一切往哪走：
- 有素材 → 方案往素材上长，省事且更像"你的作品"
- 没素材 → 纯代码生成，最可控，也完全能做

**这不是让你先去准备素材，是让你先说清楚有没有。** 做到一半发现"我其实有张图能用"，等于返工。

## 标了 2 的两段，别一次跑完

`02` 和 `05` 是**审美决定**，不是推理题。AI 只能给你选项，不能替你选。

- **第一轮**：只出 3 个方案 + 风险，**不写正文**
- **你回一句话**（「选 B」「配色用 B，字体用 C」）
- **第二轮**：写完整方案

如果你一次把整段贴进去、它直接给了你一个完整方案 —— 说明它跳过了第一轮。回一句：
**「先只给我 3 个方向的对比，不要写方案」**。

这两步被跳过，后面十个镜头会替你补上代价：风格散、返工、重做分镜。

## 六项必须你拍板的决策

在 `02` 的第一轮一起定：

| 决策项 | 可选 |
|---|---|
| 表现形式 | 纯图形 / 单主角 / 文字驱动 / 固定场景 |
| 视觉风格 | 水墨 / 像素 / 极简几何 / 拼贴 / 3D |
| 是否出现人物 | 有 / 无 / 只剪影 |
| 色彩倾向 | 冷 / 暖 / 单色 / 高对比 |
| 节奏 | 快切 / 长镜 / 混合 |
| 画幅 | 竖屏 / 横屏 / 双版本 |

## 三条经验

1. **一次只让模型干一件事**。把"解读 + 概念 + 分镜"塞进一个 prompt，出来的东西一定是四平八稳的废话。
2. **要求它给"能画出来的东西"**。看到"氛围感""情绪张力""赛博感"这种词，直接让它重写。
3. **每段都要求"反面清单"**。不给禁区，模型一定会给你星空、城市夜景、雨滴、逆光剪影这四件套。
