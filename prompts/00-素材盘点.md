# 00 · 素材盘点

**什么时候用**：建完目录、跑完分析之后，**写任何解读和方案之前**。

**为什么要在最前面**：你手上要是有现成的人物设定、参考视频、实拍背景，整个方案会往那个方向长；如果没有，就得走纯代码生成的路线。这两条路的分镜、风格、工作量完全不同。做到一半才发现"我这有个素材能用"，等于返工。

---

## 复制以下整段问自己（或让 AI 问你）

```
在开始规划之前，先盘一下手上有什么素材。有就事半功倍，没有也完全能做——纯代码生成是默认路线，不用勉强准备。

请逐项回答，没有就说「没有」。

### 1. 人物 / 角色
- 有没有指定的形象？（真人、动漫角色、自己画的、AI 生成过的）
- 有的话，有几张？是正面立绘、三视图，还是随手一张？
- 有没有必须保留的特征？（发型、服装、配饰、纹样）

### 2. 风格参考
- 有没有「就想要这种感觉」的图？（电影截图、插画、海报、别人的 MV）
- 有没有明确的配色？（色卡、品牌色、某张图里抽出来的色）
- 有没有「绝对不要这种」的反例？

### 3. 背景 / 场景
- 有没有实拍照片？（风景、街景、室内、航拍）
- 有没有必须出现的具体地点？（某个城市、某栋楼、某条街）
- 有没有自己画/生成过的场景图？

### 4. 动态素材
- 有没有要剪进去的视频片段？（实拍、延时、航拍、动效）
- 有没有 GIF / 序列帧 / Lottie 动画？
- 有没有想要模仿的镜头运动？（某个片子里的一段运镜）

### 5. 文字与标识
- 有没有必须出现的文字？（歌名题字、品牌名、slogan）
- 有没有字体要求？（必须是某种书法体、某种无衬线）
- 有没有 logo 或图形标识？

### 6. 版权状态
对上面每一项，标一下能不能用：
- 自己拍的 / 自己画的 → 可以
- AI 生成的 → 可以，但注意生成平台的商用条款
- 网上找的 → **不能直接进成片**，只能当参考
- 商业作品截图 → 只能当参考，不能进成片
```

## 素材放哪

全部丢进 `songs/<歌名>/assets/`，**不用改名、不用整理**，AI 负责归位。

```
assets/
├── character/     人物、角色、立绘、三视图、表情
├── background/    背景、场景、实拍照片、航拍
├── reference/     风格参考（别人的作品、截图、色板）
├── clip/          视频片段、GIF、序列帧、Lottie
└── README.md      这份说明
```

命名规则（尽量遵守，不遵守也能用）：

```
类型-序号-描述.扩展名
character-01-女主侧脸.png
background-03-老城区夜景.jpg
reference-01-想要的水墨质感.jpg
clip-02-雨滴特写.mp4
```

**不确定放哪就丢 `assets/` 根目录**，AI 会按内容归类。

## 素材怎么进流程

1. AI 扫描 `assets/`，把每个文件登记进 `concept/asset-manifest.json`：

```json
{
  "id": "character-01",
  "type": "character",
  "origin": "user",
  "path": "assets/character/character-01-女主侧脸.png",
  "prompt": null,
  "source": "自己画的",
  "status": "approved",
  "usedIn": ["s03", "s11"],
  "notes": "必须保留左眼下的泪痣"
}
```

`origin` 三个值：
- `user` —— 你提供的，**可以进成片**
- `ai` —— AI 生成的参考图，**默认只做参考**（1080p 下放大会糊）
- `found` —— 网上找的，**只能当参考，不能进成片**

2. 分镜的 `refs` 字段引用 `id`，不写路径。这样素材换版本不用改分镜。

3. 渲染时按 `origin` 决定用法：
   - `user` + 分辨率够 → 可以直接铺进画面
   - `ai` / `found` → 只提取色彩和构图的参考，画面本体用代码画

## 判断标准

盘点完之后，你应该能回答一句话：

> **这支 MV 的画面，有多少是「现成的」，有多少是「生成/画出来的」？**

- 全是现成的 → 那更接近剪辑，不是这个项目的路线
- 全都没有 → 走纯代码生成，没问题，最可控
- 一半一半 → 最理想。素材定调，代码补动效和歌词

---

## 一个提醒

**没有人物的歌占多数。** 抽象、风景、图形、文字驱动，都不需要角色设定。
不要为了"看起来专业"硬造一个人物，那会让片子变假。

有素材就用，没有就画。

## 没有素材时，怎么快速造一套

实测成本最低的顺序是「**先出图定风格，再出代码造素材**」：

| 步 | 谁来做 | 产出 | 作用 |
|---|---|---|---|
| 1 | ChatGPT | 角色 / 服饰 / 场景 / 道具各一张 16:9 素材板 | 几分钟确认画风、配色、比例，返工便宜 |
| 2 | Claude | 单文件 HTML 素材库，内嵌全部 SVG，每张可「⤓ SVG」下载 | 素材变成可复用的代码，能换色换姿势 |
| 3 | 你 | 把下载的 SVG 放进 `source/`，或在渲染代码里写成参数化函数 | 进成片 |

两条经验：

- **不要停在 PNG 素材板上。** 位图放大就糊，也没法换表情和姿势；一定要拿到 SVG。
- **不要直接把 SVG 当图片贴。** 贴图只能缩放；参数化（五官 / 袍色 / 表情 / 姿势 / 道具各一个参数）才能做出入场、弹跳、抖动这些动作。示例见 `songs/人生态度-王七七/project/src/emperor.js`。
