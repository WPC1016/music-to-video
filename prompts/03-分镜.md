# 03 · 分镜

**用途**：把概念切成一个个镜头，每个镜头挂在音乐的锚点上。
**输入**：`00-风格定义.md` + `02-MV概念.md` + `analysis/structure.md`
**产出**：`concept/storyboard.json`（给程序读）+ `concept/03-分镜表.md`（给人看）

---

## 切镜的硬规则

先记住这四条，再写 prompt。模型不会自己遵守，你要在 prompt 里盯着。

1. **段落边界必切**。`structure.md` 里的 lift / drop 点，一定是一个新镜头的开始。
2. **一镜 = 1–3 句歌词**。超过 3 句观众会走神；一句一切会碎。
3. **副歌镜头更短**。主歌一镜 8–12s，副歌一镜 4–6s。用镜头长短制造"紧"的感觉，不是靠加特效。
4. **前奏和间奏用空镜**。没有歌词的地方不要硬塞歌词，用母题画面撑住。

镜头总数参考：3 分钟的歌，**20–32 个镜头**。低于 15 个太拖，高于 40 个太碎。

---

## 复制以下整段

```
你是分镜师。下面是一首歌的音频结构、歌词时间轴，以及已经定好的 MV 概念和视觉风格。

请输出分镜。要求镜头时间必须落在真实的时间点上，不许自己估算。

### 输出格式：先 JSON，后表格

第一部分：一个 JSON 对象，严格按这个结构，不要加注释、不要加代码块以外的文字：

{
  "fps": {{fps}},
  "shots": [
    {
      "id": "s01",
      "start": 0.0,
      "end": 12.0,
      "section": "intro",
      "pacing": "phrase_flow",
      "mood": "空旷、起笔",
      "lyrics": [],
      "visual": "一句话描述画面，40 字以内，必须是能画出来的具体内容",
      "camera": "镜头怎么动：固定 / 缓推 / 横移 / 跟随 / 升降",
      "motion": "画面元素自己怎么动：笔触生长 / 粒子上升 / 无",
      "transition": "和上一镜的衔接：硬切 / 淡入 / 叠化 / 无",
      "refs": ["01-墨山"]
    }
  ]
}

约束：
- start/end 必须来自我给的时间点（段落边界或歌词行起点），不要自创
- 第一个镜头 start = 0，最后一个镜头 end = 全曲时长
- 相邻镜头首尾相接，不能有缝隙或重叠
- section 用我给的能量段落名（intro / lift / drop），不要自己编
- pacing 只能取 "beat_cut" 或 "phrase_flow"；安静段必须是 phrase_flow
- visual 里禁止出现："氛围感""情绪""张力""唯美""梦幻""赛博""震撼"
- camera 是镜头运动，motion 是画面元素自己的运动，两者不要写同一件事
- refs 只能是参考图的名字（不带扩展名），没有就留空数组

第二部分：人读表格

| # | 时间 | 时长 | 歌词 | 画面 | 运动 | 参考图 |
|---|---|---|---|---|---|---|

### 分配要求

- 段落边界（lift/drop）必须换镜头
- 副歌段落的镜头时长要比主歌短 30% 以上
- 全片至少有一个"静止不动"的镜头（放在情绪最低点）
- 全片至少有一个"画面元素最多"的镜头（放在情绪最高点）
- 相邻两个镜头的构图不能雷同（不要连续三个都是"中心对称的单个物体"）

---

视觉风格：
{{粘贴 00-风格定义.md 全文}}

MV 概念：
{{粘贴 02-MV概念.md 全文}}

音频结构：
- 全曲时长：{{duration}} 秒
- BPM：{{bpm}}
- 段落：
{{粘贴 structure.md 的能量段落表}}

歌词时间轴：
{{粘贴 structure.md 的歌词时间轴表，只保留"正文"行}}
```

## 输出后怎么存

1. JSON 部分存 `concept/storyboard.json`（格式参考 `songs/_template/concept/storyboard.example.json`）。
2. 表格部分存 `concept/03-分镜表.md`，顶部加一行 `> 视觉风格见 00-风格定义.md`。
3. **跑校验器**，机器先筛一遍：

```bash
npm run mv:validate -- <歌名-艺人>
```

有 `ERROR` 必须改（时间轴错位、越界、缺字段），`WARN` 自己判断。
4. 校验过了走人审清单，发现问题就回一句"第 X 个镜头改成……"，不要整段重生成。

## 人审清单（必须过）

- [ ] 每句歌词都落在某个镜头的 `lyrics` 里，没有漏句
- [ ] 时间轴首尾相接，总时长 == 全曲时长
- [ ] 情绪最高点的镜头，画面元素确实最多
- [ ] 没有任何连续三个镜头构图雷同
- [ ] 把 `visual` 单独拎出来读一遍，能想象出 20 张不同的画
- [ ] 没有一个 `visual` 里出现被禁的词

**这一关不过，不要往下走。** 分镜错了，后面全白做。
