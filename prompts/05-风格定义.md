# 05 · 风格定义（先选样式，再写规范）

**用途**：定死这部 MV 的视觉调性。**每首歌都必须重写，不要复用上一首的。**
**产出**：`concept/00-风格定义.md`，同时把色彩/字体回填到 `song.json` 的 `style` 字段。

这一步的价值：后面所有分镜和图像提示词都要引用它。没有这张卡，10 个镜头会画出 10 种风格。

**和 02 一样分两轮**：先给 3 套样式方案让人选，选完再写完整规范。
风格是审美决定，不是推理结论 —— AI 只能提供选项，不能替你定。

---

## 第一轮：给 3 套样式方案

## 复制以下整段

```
你是视觉设计指导。下面是一首歌的 MV 概念，方向已经定死了，不要改方向。

这一轮**只给样式方案，不要写完整规范**。我要先选一套。

给出 3 套视觉样式。三套必须是**三种不同的审美路线**，不是同一套换颜色。

每套按这个格式，不要多写：

### 方案 {{A/B/C}} · {{四个字的名字}}

- **一句话**：像 ______ 的 ______（参照物必须具体）
- **色板**：主色 `#XXXXXX` / 辅色 `#XXXXXX` / 点缀 `#XXXXXX`，各标占比
- **字体**：标题用 {{字体}}，歌词用 {{字体}}，字号比例 {{}}
- **质感**：{{纸纹/颗粒/扫描线/网点/无}}，强度 {{0-1}}
- **光线**：{{硬光/柔光/逆光/无影}}，方向 {{}}
- **最适合**：这套在哪一段最出彩
- **风险**：这套最容易在哪翻车（例如：暗部糊成一片、文字看不清）

最后加一行：**你推荐哪套，为什么（一句话）**。

---

MV 概念：
{{粘贴 02-MV概念.md 的第二轮全文}}

已定：表现形式 {{}}；视觉风格 {{}}；人物 {{}}；色彩倾向 {{}}；节奏 {{}}；画幅 {{}}
```

## 第一轮结束后

3 套方案粘进 `concept/00-风格定义.md` 的「样式候选」。
**等用户选**。可以只回"B"，也可以回"B 的配色 + C 的字体"。

组合是允许的 —— 用户要的往往不是整套照搬。

## 第二轮：写完整规范

## 复制以下整段

```
我选定方案 {{}}，{{如果有微调，写在这里：例如"配色用 B，字体用 C 的宋体"}}。

按这个选择写完整视觉规范。不要再给备选，不要提"也可以考虑"。

### 一、一句话调性
像 ______ 的 ______，参照物具体。

### 二、参考坐标
- 影像：哪部电影/动画/短片
- 绘画/平面：哪个画派、哪本书的插图、哪个设计师
- 材质：真实世界里能摸到的东西
- 摄影：光线类型

### 三、色彩
| 角色 | 色名 | 十六进制 | 用在哪 | 占比 |
|---|---|---|---|---|
| 主色 | | | | ~60% |
| 辅色 | | | | ~30% |
| 点缀 | | | | ~10% |

硬性要求：不超过 6 个色；点缀色全片出现不超过 5 次；给出最暗和最亮两个端点。

### 四、字体
| 用途 | 字体 | 字重 | 说明 |
|---|---|---|---|
| 标题 | | | |
| 歌词 | | | |
| 数字/英文 | | | |

加一条：排法（横排/竖排/错落）、有没有描边投影。

### 五、质感
选 2–3 种，标强度 0–1：纸纹 / 颗粒 / 扫描线 / 网点 / 玻璃反光 / 金属拉丝 / 无质感

### 六、运动
- 整体速度感：慢 / 中 / 快
- 缓动偏好：线性 / ease-out / 弹性 / 阶梯
- 常驻微动：抖动 / 呼吸 / 漂移 / 无

### 七、禁止清单
6 条，具体到颜色和元素：
- 不能出现的颜色
- 不能出现的元素（如：不要星星、不要城市天际线、不要雨滴）
- 不能出现的处理（如：不要高斯模糊发光、不要渐变彩虹）

---

MV 概念：
{{粘贴 02-MV概念.md 全文}}

已选方案：
{{粘贴第一轮选中的那套}}
```

## 两轮的判据

**第一轮**：

- [ ] 三套是三种审美路线，不是三套配色
- [ ] 每套都有具体的参照物，不是"高级感"
- [ ] 每套都写了风险

**第二轮**：

- [ ] 色彩 ≤ 6 个，有十六进制，有占比
- [ ] 一句话调性是"像 ______ 的 ______"
- [ ] 禁止清单 6 条具体到颜色和元素
- [ ] 把这张卡给一个没听过歌的人，他能画出风格接近的画面

## 怎么用这张卡

1. 存成 `concept/00-风格定义.md`。
2. 把「三、色彩」和「四、字体」抄进 `song.json`：

```json
"style": {
  "palette": ["#0B0B0C", "#C8A24A", "#8C2F27", "#E8E2D4"],
  "font": "楷体",
  "texture": "宣纸纤维 0.6 + 颗粒 0.2",
  "lighting": "顶光偏冷，边缘暖金反光"
}
```

3. 之后每一段图像提示词，开头都要带一句：`风格遵循：{{一句话调性}}，配色限定 {{主色/辅色/点缀}}`。
4. **在 `song.json` 的 `approvals.style` 里记一笔**，表示这套是你看过认可的。

## 一个判断标准

把这张卡给一个没听过这首歌的人，他能画出**风格接近**但内容不同的画面 —— 说明定住了。
如果他画出来的东西和别人画出来的差很远 —— 说明形容词太多、约束太少，回第一轮重选。
