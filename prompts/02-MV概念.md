# 02 · MV 概念（先选方向，再写方案）

**用途**：把歌词解读变成 MV 方案。
**关键**：这一步分两轮。**第一轮只给选项，不许直接写方案。**

因为表现形式（有没有人物、什么风格、什么节奏）必须由人拍板。AI 直接给一个"完整方案"，等于替人做了决定 —— 而这类决定改起来最贵。

**输入**：`01-歌词解读.md` 全文 + `analysis/structure.md`
**产出**：`concept/02-MV概念.md`

---

## 第一轮：给 3 个方向

## 复制以下整段

```
你是 MV 导演。下面是一首歌的歌词解读和音频结构。

这一轮**只给方向，不要写完整方案**。我需要先做选择。

### 一、3 个差异明显的方向

每个方向一句话说清"这是什么片子"，并且必须真的不一样 —— 不是同一个东西换配色。

格式：

| # | 方向名 | 一句话描述 | 表现形式 | 视觉风格 | 有没有人物 | 制作难度 |
|---|---|---|---|---|---|---|
| A | | | | | | 低/中/高 |

三个方向必须在**表现形式**上有差异（例如：纯图形 / 单一主角 / 文字驱动 / 固定场景），不能三个都是"一个人在走"。

### 二、六项决策建议

针对这首歌，逐项给出你的选项和你的推荐。这是要我拍板的清单：

| 决策项 | 可选 | 你的推荐 | 理由（一句话） |
|---|---|---|---|
| 表现形式 | 纯图形 / 单主角 / 文字驱动 / 固定场景 | | |
| 视觉风格 | 水墨 / 像素 / 极简几何 / 拼贴 / 3D / 其他 | | |
| 是否出现人物 | 有 / 无 / 只剪影 | | |
| 色彩倾向 | 冷 / 暖 / 单色 / 高对比 | | |
| 节奏 | 快切 / 长镜 / 混合 | | |
| 画幅 | 竖屏 / 横屏 / 双版本 | | |

### 三、每个方向的最大风险

每个方向一句话：这个做法最容易在哪翻车。

---

歌词解读：
{{粘贴 01-歌词解读.md 全文}}

音频结构：
- 全曲时长：{{duration}} 秒
- 段落：
{{粘贴 structure.md 的能量段落表}}
```

## 第一轮结束后

把 3 个方向 + 六项建议粘进 `concept/02-MV概念.md` 的「选型记录」。
**等用户回一句话**，比如"选 B，人物只要剪影，暖色"。

用户没回之前，不要进第二轮。这是硬规矩。

---

## 第二轮：写完整方案

用户选定之后，复制下面这段，把选择结果填进去。

## 复制以下整段

```
我已选定：方向 {{A/B/C}}；表现形式 {{}}；视觉风格 {{}}；人物 {{}}；色彩 {{}}；节奏 {{}}；画幅 {{}}。

现在按这个选择写完整方案。不要再提其他方向，不要给"也可以考虑"。

### 一、Logline
一句话：在什么世界 / 谁（或什么）在做什么 / 最后落到什么画面。

### 二、世界观
- 空间：具体到一个场景，不要"虚幻空间"
- 时间感：当代 / 旧时代 / 无时间
- 材质：画面的质感是什么做的（纸、金属、布、像素、胶片……）
- 光源：光从哪来（一盏灯、天光、屏幕反光、无光源）

### 三、叙事推进
说明这支 MV 靠什么往前走。如果是纯图形，说明"变化"是怎么发生的。

### 四、色彩剧本
| 段落 | 时间 | 主色 | 情绪 | 说明 |
|---|---|---|---|---|

要求：段落数 = 音频段落数；主色用中文色名 + 十六进制；相邻段落换色必须有理由。

### 五、运动语言
- 镜头怎么动
- 元素怎么进画
- 一个镜头内部有没有二次运动

### 六、三个必须出现的画面
按顺序，每个写：第几段、画面内容、为什么必须。

### 七、不要
从版权、俗套、与歌不符三个角度，各列 2 条。

---

歌词解读：
{{粘贴 01-歌词解读.md 全文}}

音频结构：
{{粘贴 structure.md 的能量段落表 + 时长 + BPM}}
```

## 两轮的判据

**第一轮**：

- [ ] 三个方向在表现形式上真不一样
- [ ] 六项决策每项都给了推荐和理由
- [ ] 每个方向的风险是具体的（不是"制作有难度"）

**第二轮**：

- [ ] 方案里没有出现被否掉的方向
- [ ] 世界观能读出材质
- [ ] 色彩剧本段落数 = 音频段落数
- [ ] 三个必现画面里至少一个反直觉
- [ ] 换一首同类型的歌，这个方案不成立

最后一条是总判据：**方案必须只对这首歌成立**。
