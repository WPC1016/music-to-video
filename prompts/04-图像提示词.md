# 04 · 图像提示词

**用途**：把分镜里的关键镜头转成图片生成提示词，出参考图。
**输入**：`03-分镜表.md` + `00-风格定义.md`
**产出**：`concept/prompts/NN-名称.md` + `refs/NN-名称.png`

---

## 先明确一件事

出的图**不进成片**。它只干三件事：

1. 定色彩和光线，让后面的代码画面有依据
2. 给 AI 编码工具看"我要的是这种感觉"（比一百句形容词管用）
3. 提前发现"这个想法画出来其实不好看"

所以：**不用追求张张精美，要追求一套看下来风格统一**。

## 出几张

不是每个镜头都出。挑 **6–10 张**：

- 每个段落的第一个镜头（定调）
- 情绪最高点
- 情绪最低点
- 你觉得最难画的那 1–2 个
- 片头/片尾（如果有题字）

## 命名

```
concept/prompts/01-墨山.md      ← 提示词
refs/01-墨山.png                ← 图
```

序号和分镜表里 `refs` 字段对得上。同一个母题出多版就加后缀 `01-墨山-b.png`，最终选一张去掉后缀。

---

## 复制以下整段

```
你是视觉提示词工程师。下面是一首歌的视觉风格定义和分镜表。请为其中指定的镜头写图片生成提示词。

每个镜头输出三段：

### {{序号}} · {{名称}}

**中文提示词**（用于 ChatGPT Image / 即梦 / 文心一格）：
一段连贯的描述，顺序为：主体 → 动作/状态 → 环境 → 构图景别 → 光线 → 材质质感 → 配色 → 画幅。
控制在 120 字以内。不要用"唯美""震撼""氛围感"这类词。

**English prompt**（用于 Midjourney / Flux / SD）：
逗号分隔的关键词串，顺序同上。不要写完整句子。
末尾加：`--ar 9:16 --style raw`（竖屏）或 `--ar 16:9`（横屏）。

**Negative**：
这一张要避免的东西，8 个以内。必须包含风格卡里的禁止项。

### 硬性要求

1. 每张提示词开头必须带色彩约束，格式：`配色仅限 {{主色}}、{{辅色}}、{{点缀色}}`
2. 每张提示词必须包含画幅：竖屏 9:16 / 横屏 16:9
3. 不出现文字、水印、logo、签名（除非该镜头明确是题字镜头）
4. 同一批图片，光线方向必须一致（都从左上，或都逆光），否则拼在一起会跳
5. 人物（如果概念里有）不露正脸，或只出现剪影/背影

### 输出顺序

按分镜时间顺序，只输出我指定的这几个镜头。

---

视觉风格：
{{粘贴 00-风格定义.md 全文}}

分镜表：
{{粘贴 03-分镜表.md 的表格}}

要出图的镜头：
{{例：s01 片头、s07 碎鳞、s15 副歌最高点、s24 收尾}}
```

---

## 出图后的处理

1. 图存 `refs/`，提示词存 `concept/prompts/`，**同名**。
2. 全部出完后，把所有图放在一个文件夹里用缩略图模式看一遍：
   - 色调是否一致
   - 有没有一张明显是别的风格
   - 有没有出现禁止清单里的东西
3. 不一致的那张重出，不要凑合。一张风格跑偏的图会把后面所有判断带偏。

## 一个反直觉的建议

**先出片头那张**。片头定调，后面所有图都拿它当参照。
片头不满意就改风格卡，不要往下出 —— 出了 10 张再回头改，等于全废。
