# 视觉风格定义

> 这一步决定后面所有画面。**每首歌必须重写，不要抄上一首。**
> 填法见 `../../prompts/05-风格定义.md`，填完把色彩和字体同步到 `../song.json` 的 `style`。
> **分两轮**：先出 3 套样式方案，人选定后再写下面的完整规范。

## 样式候选（人拍板）

### 方案 A · 旧报纸

- **一句话**：像被雨打湿又晒干的旧报纸，边角发脆，一碰掉渣。
- **色板**：报纸黄 `#E8E0CC` 60% / 墨黑 `#14110F` 30% / 朱红 `#B33A2B` 10%
- **字体**：标题 思源宋体 Heavy，歌词 楷体，数字 Courier
- **质感**：纸张纤维 0.5 + 印刷网点 0.3
- **光线**：平光无影为主，局部一盏顶灯的硬阴影
- **最适合**：主歌那些懒散的段落。报纸的廉价感 = 他对生活的态度
- **风险**：整片偏黄容易显脏，久了像发霉。**必须靠墨黑压住**，黑占不到 30% 就会糊成一片

### 方案 B · 复印纸

- **一句话**：像办公室打印机卡纸时吐出来的那张，有折痕、有碳粉印、边上有撕口。
- **色板**：复印纸白 `#F2F0EB` 65% / 碳粉黑 `#1A1A1A` 25% / 荧光橙 `#FF5A1F` 10%
- **字体**：标题 思源黑体 Black，歌词 等宽字体，数字 等宽
- **质感**：纸纹 0.2 + 碳粉颗粒 0.6
- **光线**：冷白顶光，硬阴影，无柔和过渡
- **最适合**：副歌那些说理的段落。冷、硬、不容置疑
- **风险**：太"办公室"，和市井气不搭。荧光橙用不好会像促销海报

### 方案 C · 牛皮纸箱

- **一句话**：像搬家用的纸箱，被胶带缠过几道，上面用记号笔写着字。
- **色板**：牛皮棕 `#C8A06A` 60% / 墨黑 `#14110F` 25% / 朱红 `#B33A2B` 15%
- **字体**：标题 记号笔手写体，歌词 思源黑体，数字 手写
- **质感**：瓦楞纹 0.7 + 胶带反光 0.2
- **光线**：单侧暖光，长阴影
- **最适合**：全片，尤其"收拾东西 / 搬家"那种叙事
- **风险**：棕色偏暖，容易滑向"复古文艺"，和"混不吝"差一口气

### 选定

- 选了：**A 的配色 + C 的瓦楞质感**
- 微调：主色保留报纸黄，质感换成瓦楞沟槽；瓦楞方向垂直，间距按画面宽度 0.55% 递增

## 字体

| 用途 | 字体 | 字重 | 说明 |
|---|---|---|---|
| 标题 | 思源宋体 Heavy | 900 | 歌名、段落转换处的字卡，竖排 |
| 歌词 | 楷体（退化到 思源宋体 Light） | 400 | 横排居中偏下，字号 = 画面高度 3.2% |
| 数字/英文 | Courier New Bold | 700 | 时间码、编号、报纸纹理里的乱码 |

排法：歌词无描边、无投影，靠墨黑色压住纸黄底。**不逐字高亮、不做卡拉 OK 效果** —— 这首歌不配。

## 质感

**全部程序化生成，不用任何外部图片。**

| 质感 | 强度 | 代码怎么实现 |
|---|---|---|
| 瓦楞纹 | 0.35 | 每 6px 画一条 1px 深色竖线，alpha 0.06；按 `sin(y/40)` 微调间距，避免死板 |
| 纸张纤维 | 0.5 | 固定种子的 value noise，横向拉伸 8 倍，叠到底色上，alpha 0.12 |
| 印刷网点 | 0.25 | 只在朱红区域：4px 网格圆点，半径随局部亮度变化（0.6–1.4px） |
| 边缘毛刺 | 0.6 | 矩形四个顶点按 `mulberry32(seed)` 偏移 1–2px，用 path 填充，不用 `fillRect` |

**铁律：同时叠加不超过 3 种。** 超过就糊成噪点。

### 纯代码生成原则

1. **零外部素材**。没有 png、没有 svg、没有字体文件。所有像素由 canvas 画出来。
2. **固定种子**。每个镜头一个 seed（`hash(shotId)`），纹理和毛刺每次渲染完全一致。
3. **只用四种原语**：矩形、圆、多边形、线段。复杂物件用这四个拼。
4. **文字用系统字体**。`KaiTi` / `SimSun` / `Microsoft YaHei`，按可用性降级，不加载 webfont。
5. **不用 blur、不用 shadowBlur**。所谓"阴影"是把形状复制一份、偏移、填纯色、降低透明度，得到硬边。

## 运动

- **速度感**：慢。全片平均镜头长度 8 秒以上。
- **缓动**：`ease-out` 为主。**不用弹性（elastic/back）**，纸不会被弹回来。
- **常驻微动**：
  - 纸片人呼吸：整体上下 1–2px，阴影同步缩放
  - 报纸纹理漂移：0.02px/帧，几乎察觉不到
  - 纸边卷动：每 8–12 秒一次，幅度 2–3px

## 禁止清单

1. **不要纯白 `#FFFFFF`**。最亮只到 `#F5F0E4`。这个片子里不存在干净的白纸。
2. **不要渐变**。所有色块必须是平的，过渡只能靠网点密度或物理遮挡。
3. **不要高斯模糊、不要发光、不要柔和投影**。所有阴影必须是硬边。
4. **不要蓝色系**。全片不出现任何蓝 —— 包括天空、水、屏幕光、夜景色调。
5. **不要圆角矩形和现代 UI 元素**。按钮、卡片、进度条、圆角头像一律不用。
6. **报纸上的文字必须是不可读的乱码**。不要出现真实新闻内容，一是版权，二是会抢注意力。
