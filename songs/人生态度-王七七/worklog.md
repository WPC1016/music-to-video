## 这首歌的要点

- 民谣摇滚，BPM 估计 109.5，全曲 155.99s，6 个能量段落
- 52 行正文歌词（另有 14 行制作信息，已标 `meta` 不上屏）
- 画幅竖屏 1080×1920 / 30fps

**核心判断**：这首歌是**黑色幽默的豁达**，不是正能量励志。
「房子着火我拍照」「大不了我就上吊」都是玩笑，是在用荒诞消解苦难。
做成励志片就废了。详见 `concept/01-歌词解读.md` 的「叙事线」和「禁区」。

## 已知问题

- BPM 109.5 是算法估计，需要人工跟着节奏数一遍确认
- 段落切点：0s / 12s / 26s / 80s / 95s / 138s。26–80s 之间只有一次切分，跨度过大，分镜时按歌词行补切
- 「上吊」这句是平台红线，任何具象化都不行，建议整句留白

## 2026-10-22 · 从零重做（v2 素材库驱动）

用户要求重做全片，依据是素材库 HTML 里已经实现得很好的两件事：**歌词条四段动画**与「动画示例 · 关键镜头」。

**新架构**（`project/src/`）

| 文件 | 职责 |
|---|---|
| `emperor.js` | 素材库本体：角色/服饰/道具/场景/印章/歌词条的 SVG 生成器（含新增 `SCENES.hill` 煤山） |
| `director.js` | 55 镜调度表 + 绘制：场景、色调、人物入场与持续动作、环境动效、道具图标、特殊演出 |
| `fx.js` | 环境动效层：火星/青烟/浮尘/花瓣/水波/风/星/纸屑/裂缝/声波/药丸/金光 |
| `main.js` | 时间轴、预加载、镜头运动、歌词条关键帧、后期（颗粒+暗角+片头尾淡入淡出） |

**镜头语言**：入场（pop / rise / drop / slide，overshoot 回弹）→ 持续动作（bounce / shake / sink / sway / nod）→ 道具大图标（带名称，浮在与人物相反一侧）→ 镜头缓推/平移 → 歌词条动画。

**歌词条动画**（对齐素材库 CSS keyframes）：0–0.4s 上浮+放大到 1.05 → 0.55s 缩到 0.97/转 -1.2° → 0.7s 1.02/+1° → 0.85s 归位 → 行尾前 0.32s 开始淡出；印章由 2.6 倍/-24° 砸到 1 倍/-8°；进度条随行推进。

**特殊演出**

- `s01` 竖排纸卷轴标题 + 「态度」朱印
- `s02` 拍立得（内嵌火烧场景缩略图 + 「清君侧」）
- `s25` / `s48` 「态度」大印从右侧砸下（避开人脸）
- `s32` 空殿 + 纸飘落
- `s55` 纸卡片版「明代皇帝 × 人生态度」对照表（8 行 + 副题 + 脚注 + 朱印）
