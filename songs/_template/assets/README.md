# 素材放这里

手上有什么就丢进来，**不用改名、不用整理**，AI 负责归位。

```
character/    人物、角色、立绘、三视图、表情
background/   背景、场景、实拍照片、航拍
reference/    风格参考（别人的作品、截图、色板）
clip/         视频片段、GIF、序列帧、Lottie
```

不确定放哪就丢这个目录的根下。

**没有素材完全没问题**，纯代码生成是默认路线。

## 版权

| 来源 | 能不能进成片 |
|---|---|
| 自己拍的 / 自己画的 | 可以 |
| AI 生成的 | 可以（注意生成平台的商用条款） |
| 网上找的 | 不能，只能当参考 |
| 商业作品截图 | 不能，只能当参考 |

登记进 `../concept/asset-manifest.json` 时用 `origin` 字段标清楚：`user` / `ai` / `found`。

详细盘点清单见项目根 `prompts/00-素材盘点.md`。
